# Jira Time Logger — macOS

Инструмент для логирования времени в Jira без терминала.
Работает на любом Mac: и Apple Silicon (M1–M4), и Intel.

## Как установить

1. Открой файл **`JiraTimeLogger.dmg`** (двойной клик) — на экране появится окно
   с диском «Jira Time Logger», внутри него лежит приложение **JiraTimeLogger**.
2. **Обязательно перетащи `JiraTimeLogger` из этого окна в папку «Программы»**
   (Applications) — установка и состоит в этом переносе. Проще всего перетащить
   на «Программы» в боковой панели Finder.
3. Дальше запускай приложение **только из «Программ»**. Сам `JiraTimeLogger.dmg`
   после переноса больше не нужен — его можно удалить.

Не запускай приложение прямо из окна диска: диск смонтирован временно, после
извлечения или перезагрузки такой запуск перестанет работать, а приложения
в «Программах» у тебя не появится.

## Первый запуск (важно, один раз)

Приложение не подписано в Apple, поэтому macOS при первом запуске его блокирует —
это нормально, шаги ниже нужны только один раз.

1. Запусти **JiraTimeLogger** из «Программ» (двойной клик). macOS покажет окно
   вида «Не удалось проверить разработчика» — нажми **«Готово»**.
2. Открой **Системные настройки → Конфиденциальность и безопасность**, прокрути
   до раздела «Безопасность»: там будет строка про JiraTimeLogger и кнопка
   **«Открыть всё равно»** — нажми её и подтверди паролем.
3. Дальше приложение запускается обычным двойным кликом, без вопросов.

## Как пользоваться

1. После запуска откроется браузер с формой. В «Настройках подключения» один раз введи
   **логин** (фамилия на латинице, например `ivanov`) и **пароль** (или API-токен).
   Адрес Jira подставляется сам — вводить его не нужно.
   Настройки сохранятся в браузере — вводить каждый раз не нужно.
2. Заполни задачи: для каждой — **дата**, **ключ** (например `DT-43`), **время**
   (`2h` / `1.5h` / `30m`) и **комментарий**. Дату можно выбрать в календаре по иконке.
   Кнопки **«Добавить»** и **«Дублировать»** добавляют строки.
3. Нажми **«Залогировать»** — время уйдёт в Jira, по каждой строке будет результат.

## Важно

- Нужен доступ к корпоративной сети, где живёт Jira (часто — через **VPN**).
  Если пишет «Не удалось подключиться к Jira» — проверь VPN.
- Программа открывает маленький локальный сервер только на твоём компьютере. Когда
  закроешь вкладку браузера — он выключится сам через несколько секунд.
- Если шаг с «Открыть всё равно» не помог, то же самое делает одна команда в
  «Терминале» (снимает метку карантина с приложения):

  ```
  xattr -dr com.apple.quarantine /Applications/JiraTimeLogger.app
  ```
