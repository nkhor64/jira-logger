# Jira Time Logger — Windows

Инструмент для логирования времени в Jira без терминала.

## Как запустить

1. Скачай файл **`JiraTimeLogger.exe`** (он в этой папке).
2. Дважды кликни по нему.
3. Откроется браузер с формой. В «Настройках подключения» один раз введи:
   - **Jira URL** (например `https://jira.ap-team.ru`)
   - **Логин** и **пароль** (или API-токен)

   Настройки сохранятся в браузере — вводить каждый раз не нужно.
4. Заполни задачи: для каждой — **дата**, **ключ** (например `DT-43`), **время**
   (`2h` / `1.5h` / `30m`) и **комментарий**. Дату можно выбрать в календаре по иконке.
   Кнопки **«Добавить»** и **«Дублировать»** добавляют строки.
5. Нажми **«Залогировать»** — время уйдёт в Jira, по каждой строке будет результат.

## Важно

- Нужен доступ к корпоративной сети, где живёт Jira (часто — через **VPN**).
  Если пишет «Не удалось подключиться к Jira» — проверь VPN.
- Если Windows показывает «неизвестный издатель»: нажми **«Подробнее» → «Выполнить
  в любом случае»**. Файл безопасен — это локальная программа без цифровой подписи.
- Программа открывает маленький локальный сервер только на твоём компьютере. Когда
  закроешь вкладку браузера — он выключится сам через несколько секунд.
